# Internationalisation

Le kit parle `vue-i18n` nativement. Il fournit ses messages de base (**fr** et
**en**) sous un namespace dédié — vos propres messages vivent à côté, sans
collision, et peuvent **surcharger** ceux du kit.

## Installer

```ts
import { createForgeI18n } from "@/i18n"

const i18n = createForgeI18n({
  locale: "fr",            // défaut : "fr"
  fallbackLocale: "en",    // défaut : "en"
})

app.use(i18n)
```

## Ajouter vos messages

Passez-les à `createForgeI18n` — ils sont fusionnés **au-dessus** de ceux du
kit (vous gagnez en cas de conflit) :

```ts
const i18n = createForgeI18n({
  locale: "fr",
  messages: {
    fr: {
      dashboard: { title: "Vue d'ensemble" },
      // Surcharger une clé du kit :
      forge: { actions: { new: "Ajouter" } },
    },
    en: {
      dashboard: { title: "Overview" },
    },
  },
})
```

Dans vos composants, `useI18n()` classique :

```vue
<script setup lang="ts">
import { useI18n } from "vue-i18n"
const { t } = useI18n()
</script>

<template><h1>{{ t("dashboard.title") }}</h1></template>
```

## Changer de langue à chaud

`locale` est réactif — un sélecteur suffit :

```ts
import { useI18n } from "vue-i18n"

const { locale } = useI18n()
function setLocale(l: string) {
  locale.value = l
  localStorage.setItem("app:locale", l)   // persistez où vous voulez
}
```

Toutes les chaînes du kit (boutons, pagination, confirmations, formulaires…)
basculent instantanément.

## Ajouter une langue au kit

Le kit fournit fr et en. Pour une autre langue, fournissez les clés du
namespace du kit dans vos `messages` (avec `fallbackLocale` pour les trous) :

```ts
createForgeI18n({
  locale: "es",
  messages: {
    es: {
      forge: {
        actions: { new: "Nuevo", edit: "Editar", delete: "Eliminar", /* … */ },
        index: { search: "Buscar…", /* … */ },
        // …voir ui/i18n/fr.ts pour la liste complète des clés
      },
    },
  },
})
```

## Dans les composants du kit

Interne au kit (et utile pour vos composants custom de champ) : `useForgeT()`
préfixe automatiquement le namespace — `t("actions.edit")` au lieu de
`t("forge.actions.edit")`. Le namespace vit dans `brand.ts`, jamais dans les
templates.

::: tip Libellés de resources
Les `label` de resources et de champs sont déclarés côté serveur et arrivent
en props — ils ne passent pas par vue-i18n. Pour un back-office multilingue
au niveau des données elles-mêmes, déclarez vos defs avec les libellés de la
langue de vos opérateurs.
:::
